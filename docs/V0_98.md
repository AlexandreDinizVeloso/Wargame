# Concórdia v0.98 · Gold Candidate

Branch `feat/v0.98-gold-ambition`, baseada em `2494a7ae`. Aplicação **0.98.0**, protocolo e snapshots **7**. Novas campanhas recebem `ruleset: GOLD_098`; salas anteriores e tutorial conservam suas regras. Não há migração silenciosa de dinheiro, tropas ou ordens de uma campanha existente.

## Mapa e comandos

| Atalho | Lente / ação                                         |
| ------ | ---------------------------------------------------- |
| F1     | Política: propriedade e ocupação                     |
| F2     | Economia: renda local efetiva, recursos ampliados    |
| F3     | Logística: suprimento, consumo e isolamento          |
| F4     | Diplomacia: própria nação ou referência inspecionada |
| F5     | Pacificação, fé e revolta                            |
| O      | Abrir/recolher Outliner                              |
| Tab    | Selecionar e centralizar próxima formação sem ordem  |

Esquerdo seleciona/inspeciona; direito move/ataca; Alt + esquerdo sinaliza. Atalhos de seleção não interceptam campos de formulário. O Outliner reúne batalhões, frotas e até cinco províncias com construções acessíveis. Janelas móveis e redimensionáveis da v0.95 permanecem disponíveis.

A renda da lente econômica é a contribuição local de impostos/comércio, incluindo modificadores locais; dízimos, corrupção, reparações e outros fluxos nacionais aparecem no orçamento da nação. A lente logística usa consumo ponderado, incluindo a redução da cavalaria de Turan.

## Facções e eras

Cada nação tem uma passiva estruturada, exibida na seleção, HUD e diplomacia: comércio/fretamento de Véspera; pacificação e moral de Aurélia; artilharia de Kaldor; cavalaria de Turan; inverno e choque de Ferro-Norte; experiência e construções de Sapiência; fortificações e mobilização do Sol Invicto; terreno e atrito de Verídia.

- **Rodadas 1–8, Fronteiras:** integração de neutros reduzida e proteção inicial das capitais.
- **Rodadas 9–20, Comércio & Impérios:** comércio marítimo +35%, tecnologias Tier 2 −10%, reforço de cidades neutras sem cerco ativo.
- **Rodadas 21+, Guerra Total & Hegemonia:** cerco +1, prestígio e pontuação de vitórias em dobro, aviso de aproximação da hegemonia.

## Tratados e IA

War Score é recalculado a partir de ocupações (12; capital original 25), saldo de vitórias (4, teto 40; multiplicador da era final) e bloqueios navais reais (5 por porto). O resultado fica entre −100 e +100.

| Cláusula                    |       Pontos | Efeito                                                                    |
| --------------------------- | -----------: | ------------------------------------------------------------------------- |
| Paz branca                  |            0 | Encerra guerra e devolve ocupações; exclusiva                             |
| Cessão territorial          | 20/província | Transfere terras ocupadas selecionadas                                    |
| Reparações                  |           25 | 25% da receita bruta por cinco resoluções                                 |
| Humilhação/desmilitarização |           30 | +15 prestígio ao vencedor, quatro rodadas de desarmamento, seis de trégua |
| Vassalagem                  |           75 | Subordina o derrotado, sem ciclos de vassalagem                           |

Cláusulas podem ser combinadas dentro do orçamento; a opção de concessão inverte quem recebe os benefícios. Reparações aparecem na previsão e no relatório financeiro; pagamentos respeitam os fundos disponíveis. Pedidos são revalidados na aceitação.

Bots aceitam termos compatíveis com a pontuação, oferecem concessões quando derrotados e exaustos, e reagem a hegemonias com coalizões preventivas. Despachos temáticos têm limite global de uma mensagem de bot por rodada.

## Saves e convites

O anfitrião exporta um **Save JSON completo**, sem credenciais de sessão. Importar cria uma sala privada com novo código, preservando campanha, ordens, tesouros, tropas, histórico e estado aleatório. O relógio/readiness é reiniciado para permitir reunir o grupo.

Jogadores humanos importados recebem novos convites individuais para suas vagas. O anfitrião copia esses links no Conselho; cada amigo abre seu próprio link e retoma a nação correspondente. Tokens anteriores não concedem acesso à nova sala. Trate convites individuais como credenciais privadas.

Relatórios antigos com `finalState` ou estados públicos podem ser importados como **novos cenários visíveis**: ordens privadas são zeradas, objetivos secretos desativados e o estado aleatório é novo. A interface identifica essa origem. Para continuidade integral, use Save JSON completo. Limite de arquivo: 8 MiB.

O selo Friend-Pass e o convite comum `?room=CODIGO` estão disponíveis no lobby. Esse convite preenche o código; o convidado ainda escolhe nome/nação e entra na sala. Não existe cobrança nem verificação de compra nesta versão.

## Desktop

Requer as dependências normais do projeto e as dependências separadas do cliente:

```sh
npm ci --include=dev
npm run build
npm ci --prefix desktop
npm run desktop:dev
```

No PowerShell, use `npm.cmd` nos mesmos comandos. O cliente Electron inicia um servidor local isolado, vinculado a `127.0.0.1`, em porta disponível, com saves no diretório de dados do aplicativo. Para conectar a um servidor compartilhado:

```powershell
$env:CONCORDIA_SERVER_URL='https://play.seu-dominio.com'
npm.cmd run desktop:dev
```

O servidor compartilhado segue [DEPLOY_CLOUD.md](DEPLOY_CLOUD.md) ou [REDE.md](REDE.md). O servidor interno do desktop serve apenas esta máquina. Radmin/IPv6 continuam possíveis com o servidor Node configurado para ouvir a interface de rede apropriada.

```sh
npm run desktop:package
```

Esse comando gera a pasta executável em `.local/desktop-build`, no sistema operacional atual. Para um instalador, execute `npx electron-builder --win portable`, `--linux AppImage` ou `--mac dmg` dentro de `desktop`, em ambiente compatível. Binários publicados, assinatura, notarização, Steamworks SDK, loja e conquistas oficiais Steam exigem uma etapa de distribuição própria. A versão entrega o cliente funcional e a configuração de empacotamento.

O renderer usa sandbox, isolamento de contexto e Node desabilitado. O processo principal encerra o servidor local ao sair. Não são incluídas salas locais no pacote.
