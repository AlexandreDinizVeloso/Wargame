# Cenários cinematográficos · v1.2

`land-battlefield.webp` e `naval-battlefield.webp` foram gerados para Concórdia com uma ferramenta de geração de imagens e comprimidos para entrega no navegador. São cenários de apresentação; não representam fronteiras, exércitos ou resultados da partida.

As formações, navios, disparos, partículas, fumaça e movimentos são desenhados e animados pelo Canvas do navegador. As forças, baixas, moral e resultados exibidos nas cenas de campanha vêm dos relatórios do servidor. A galeria identifica seus dados de exemplo como prévias encenadas.

Os arquivos são servidos localmente, sem depender de serviços externos durante o jogo.
